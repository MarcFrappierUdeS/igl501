Q6 - Solution

I = x ∈ 1..2 ∧ y : 0..3 & y+x <= 3

Init : l'invariant est préservé

    [x := 1 || y := 2]I
<=>
    1 ∈ 1..2 ∧ 2 : 0..3 & 2+1 <= 3
<=>
    true

Op1 : l'invariant n'est pas préservé pour le cas  

P = TRUE

Supposons I et calculons [S]I

    [CHOICE x := 2 OR y := 2 END]I
<=>   { application CHOICE }
    [x := 2]I & [y := 2]I
<=>   { substitution }
      (2 ∈ 1..2 ∧ y : 0..3 & y+2 <= 3)
    & (x ∈ 1..2 ∧ 2 : 0..3 & 2+x <= 3)
<=>   { logique et arithmétique }
      y : 0..1
    & x = 1

Mais en hypothèse, on a que (x=1 & y : 0..2) or (x=2 & y : 0..1).
Dans les deux cas, cela contredit [S]I

On peut le vérifier dans ProB avec la formule suivante), qui est fausse

!(x,y).((x ∈ 1..2 ∧ y : 0..3 & y+x <= 3) => ((2 ∈ 1..2 ∧ y : 0..3 & y+2 <= 3) & (x ∈ 1..2 ∧ 2 : 0..3 & 2+x <= 3)))


Op2: l'invariant est préservé

P = x > 1
I = x ∈ 1..2 ∧ y : 0..3 & y+x <= 3

Supposons I & P, ce qui donne
x=2 & y=1


 et montrons [S]I

    [ANY z WHERE z ∈ x..y THEN x := x+z || y := y+z END]I
<=>
    !z.(z ∈ x..y => [x := x+z || y := y+z]I)
<=>    { Hypothèse x=2 & y=1 }
    !z.(z ∈ 2..1 => [x := x+z || y := y+z]I)
<=>
    !z.(false => x+z ∈ 1..2 ∧ y+z : 0..3 & y+z+x+z <= 3)
<=>
    !z.(true)
<=>
    true
